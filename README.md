## Français

### Présentation
irisv1.21.4 est un devkit Minecraft 1.21.4 base sur NeoForge. Il fournit une base de mod avec tooltips, HUD, menus, providers et configuration JSON. Le depot sert au developpement d'experimentations et d'outils Minecraft personnels.

### Fonctionnalités
- Base NeoForge pour Minecraft 1.21.4.
- Tooltips avances pour blocs, entites, objets, inventaires et fluides.
- Indicateurs HUD et menus IrisV.
- Configuration JSON et synchronisation reseau.

### Installation
Installe un JDK compatible, puis utilise les scripts Gradle fournis (gradlew ou gradlew.bat) pour preparer l'environnement.

### Utilisation
Lance les taches Gradle de developpement ou ouvre le projet dans ton IDE Minecraft/NeoForge. Ce depot reste un projet de developpement interne.

## English

### Overview
irisv1.21.4 is a Minecraft 1.21.4 devkit based on NeoForge. It provides a mod base with tooltips, HUD indicators, menus, providers and JSON configuration. The repository supports personal Minecraft experiments and tools.

### Features
- NeoForge base for Minecraft 1.21.4.
- Advanced tooltips for blocks, entities, items, inventories and fluids.
- IrisV HUD indicators and menus.
- JSON configuration and network synchronization.

### Installation
Install a compatible JDK, then use the provided Gradle scripts (gradlew or gradlew.bat) to prepare the environment.

### Usage
Run the development Gradle tasks or open the project in your Minecraft/NeoForge IDE. This repository remains an internal development project.
