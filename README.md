## Français

### Présentation
irisv1.21.1 est un devkit Minecraft 1.21.1 base sur NeoForge 21.1.222. Il fournit une base de mod avec tooltips, HUD, menus, providers et configuration JSON. Le depot sert au developpement d'experimentations et d'outils Minecraft personnels.

### Fonctionnalités
- Base NeoForge pour Minecraft 1.21.1.
- Tooltips avances pour blocs, entites, objets, inventaires et fluides.
- Indicateurs HUD et menus IrisV.
- Configuration JSON et synchronisation reseau.

### Installation
Installe Java 21, puis utilise les scripts Gradle fournis (`gradlew` ou `gradlew.bat`) pour preparer l'environnement.

### Utilisation
Lance les taches Gradle de developpement ou ouvre le projet dans ton IDE Minecraft/NeoForge. Ce depot reste un projet de developpement interne.

Commandes utiles :

```text
gradlew runClient
gradlew runServer
gradlew runData
gradlew build
```

## English

### Overview
irisv1.21.1 is a Minecraft 1.21.1 devkit based on NeoForge 21.1.222. It provides a mod base with tooltips, HUD indicators, menus, providers and JSON configuration. The repository supports personal Minecraft experiments and tools.

### Features
- NeoForge base for Minecraft 1.21.1.
- Advanced tooltips for blocks, entities, items, inventories and fluids.
- IrisV HUD indicators and menus.
- JSON configuration and network synchronization.

### Installation
Install Java 21, then use the provided Gradle scripts (`gradlew` or `gradlew.bat`) to prepare the environment.

### Usage
Run the development Gradle tasks or open the project in your Minecraft/NeoForge IDE. This repository remains an internal development project.

Useful commands:

```text
gradlew runClient
gradlew runServer
gradlew runData
gradlew build
```
